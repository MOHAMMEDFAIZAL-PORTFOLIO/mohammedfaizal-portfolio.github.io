# Mohammed Faizal M — Portfolio

1. Extract this ZIP.
2. Upload `index.html`, `style.css`, and `README.md` to the root of `mohammedfaizal-portfolio.github.io`.
3. Add your selected professional portrait in the same root folder, named exactly `profile.jpg`.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
6. After publishing, visit `https://mohammedfaizal-portfolio.github.io`.

The education date ranges shown in the template should be checked before publishing. The profile image is a placeholder until you add `profile.jpg`.
